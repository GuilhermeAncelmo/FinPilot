# FinPilot 💸

<p align="center">
  Plataforma moderna de gestão financeira pessoal para controle inteligente de receitas, despesas e planejamento financeiro.
</p>

---

## ✨ Funcionalidades

* Cadastro e gerenciamento de receitas
* Controle de despesas por categoria
* Dashboard financeiro interativo
* Visualização gráfica de movimentações
* Projeção de fluxo de caixa futuro
* Cálculo de capacidade segura de gasto
* Metas financeiras e acompanhamento
* Interface moderna, responsiva e intuitiva

## 🎯 Objetivo

O FinPilot foi desenvolvido para transformar a gestão financeira pessoal em uma experiência **visual, estratégica e inteligente**, permitindo ao usuário acompanhar sua saúde financeira e planejar seus próximos passos com mais clareza e segurança.
